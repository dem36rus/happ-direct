Добавить сайты

По одному адресу на строку. Можно вставлять домены, маски или полные ссылки:

  1. Добавьте сайты и нажмите «Установить / Обновить в Happ».
  2. В Happ откройте «Настройки → Правила маршрутизации → ⋯ → Импорт профиля из буфера».
  3. Выберите vless.ugol.red и подтвердите замену «My Cloud Direct».
  4. Переподключите Happ, чтобы применить исключения.

Профиль: My Cloud Direct, подписка vless.ugol.red. После первого применения ненужный профиль из «Списка серверов» можно удалить.

При подключённой подписке список сохраняется на сервере и передаётся через 3x-ui в Happ. До нажатия кнопки изменения остаются только в этом браузере.
