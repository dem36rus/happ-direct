# Адаптер маршрутизации для 3x-ui

`server.py` работает только на loopback. Точный адрес одной подписки в Nginx направляется на `/subscription`; остальные подписки продолжают обслуживаться 3x-ui напрямую. Адаптер передаёт исходное тело ответа 3x-ui и добавляет стандартные заголовки `Routing` и `Routing-Enable`. Он не меняет UUID, пароли, адреса, транспорт или конфигурацию Xray. У 3x-ui параметры Reality `sid` и `spx` могут различаться между запросами из-за собственного случайного выбора панели.

`/profile` принимает GET/POST/OPTIONS через HTTPS reverse proxy. Bearer-ключ обязателен для чтения и записи; браузерный CORS разрешён только для GitHub Pages этого проекта. POST принимает только список `directSites` и текущую `expectedRevision`: неизвестные категории, некорректные домены и конфликт обновлений отклоняются. Полный профиль собирается из серверного шаблона. Запись атомарна; при ошибке старые правила сохраняются. Форма не должна показывать успех до ответа 200.

Секретный конфиг `/etc/happ-direct/config.json` передаётся сервису через systemd `LoadCredential`. Состояние хранится в приватном `StateDirectory`. Сервис использует `DynamicUser`, `ProtectSystem=strict` и отдельный непривилегированный процесс. Ключи, URL с идентификаторами подписок и резервные копии Nginx не размещаются в репозитории. Логи HTTP-запросов в адаптере отключены, чтобы не сохранять ключи.

Шаблон конфигурации должен включать `api_key`, `allowed_origin`, `template`, `initial_rules`, `allowed_geosite_tags`, `state_path`, `subscription_url`, `upstream_url`, `upstream_host`, `port`. `upstream_url` настраивается администратором на локальный HTTPS-порт 3x-ui. Пользовательский запрос не может менять этот адрес. Проверка сертификата для этого loopback-подключения отключена: сертификат подписан для публичного домена, а не для 127.0.0.1. Публичные HTTPS-запросы проверяют сертификат обычным способом.

Юнит: `happ-direct.service`. Перед изменением Nginx сохраняется приватная резервная копия и выполняется `nginx -t`. Активация — graceful reload Nginx; Xray и 3x-ui не перезапускаются. Для отката администратор восстанавливает прежний конфиг Nginx, проверяет его и выполняет reload, после чего отключает этот сервис.

Проверка: `PYTHONPATH=integration python3 -m unittest discover -s integration -v`. Тесты покрывают авторизацию, CORS, неизменность состояния при ошибках, атомарное сохранение, конфликт ревизий, IDN, передачу тела исходной подписки, профиль в заголовке и ошибку upstream.
