# Happ Direct

Форма исключений для подписки `vless.ugol.red`: https://dem36rus.github.io/happ-direct/.

## Сохранение через подписку 3x-ui

Один раз откройте персональную ссылку подключения в используемом браузере. Она сохраняет отдельный ключ управления списком, затем удаляет его из адресной строки. Ключ не является паролем панели или VPN-ключом и не публикуется в репозитории.

В Happ у подписки `vless.ugol.red` выключите «Игнорировать импорт роутинга». Впишите сайты в форму и нажмите «Установить / Обновить в Happ». Страница подтвердит сохранение только после ответа сервера. Затем обновите подписку в Happ круговой стрелкой и переподключитесь. Профиль `My Cloud Direct` приходит вместе с этой подпиской и используется всеми четырьмя её обычными подключениями. Отдельный импорт профиля из буфера не требуется.

Сервер принимает список только с ключом. Существующая ссылка подписки и параметры подключений остаются прежними. Веб-форма не передаёт пароль панели и не меняет серверные правила Xray: Direct выполняется на клиентском компьютере. В этой версии связка реализована через [адаптер подписки](integration/README.md), который добавляет стандартный заголовок `Routing` к ответу 3x-ui только для одной настроенной подписки.

Ненужный профиль `My Cloud Direct` в «Списке серверов» можно удалить после применения профиля подписки. Если ключ подключения не задан, форма сохраняет прежний способ ручного импорта через буфер в выбранную подписку.

## Российские маршруты

Включены проверенные категории `category-bank-ru`, `category-gov-ru`, `category-ecommerce-ru`, `category-travel-ru`, `yandex`, `mailru-group`, общий `category-ru` и российские доменные зоны `tld-ru`. Используется GeoSite Loyalsoldier; все восемь тегов проверены в скомпилированном `geosite.dat` перед публикацией. Также напрямую идут `geoip:ru` и локальные IPv4/IPv6-сети. Список `category-ru` охватывает российские доменные зоны и основные российские сервисы, включая сервисы вне зоны `.ru`.

Явно внесены `mosenergosbyt.ru`, `vseinstrumenti.ru`, `lemanapro.ru`, `max.ru` и `oneme.ru`. Обратные слеши в конце строк при вставке убираются. Собственные дополнения сохраняются на сервере кнопкой формы и загружаются в других подключённых браузерах. Несохранённый ввод остаётся локальным.

Базовый открытый список — `direct.txt`. Кнопка экспорта позволяет сохранить итоговый список отдельно. Готовые JSON-конфигурации имеют свои правила; обновите обычную подписку, если раньше вручную меняли JSON подключения.
