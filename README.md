# happ-direct
Список исключений Direct и форма для Happ: https://dem36rus.github.io/happ-direct/.

Добавьте сайты в форму и нажмите «Скопировать профиль для Happ». В Happ откройте «Настройки → Правила маршрутизации → ⋯ → Импорт профиля из буфера», выберите подписку `vless.ugol.red` и подтвердите замену `My Cloud Direct`. Переподключите Happ.

Для следующих изменений повторяйте импорт в ту же подписку. Так обновляется один профиль, который используют все её обычные VLESS/Trojan-подключения. Готовые JSON-конфигурации имеют собственные правила; правка их JSON не заменяет этот способ импорта.

Если остался отдельный `My Cloud Direct` в «Списке серверов», сначала перенесите нужные сайты в форму и импортируйте профиль в `vless.ugol.red`, затем удалите ненужный профиль из «Списка серверов». Кнопка формы копирует профиль и не открывает `happ://routing/onadd/`: прямое открытие такой ссылки в Happ 4.6.1 создаёт/обновляет общий профиль без выбора подписки.

Добавленные строки хранятся в браузере. Для синхронизации списка между компьютерами скопируйте итоговый `direct.txt`, сохраните его в этом репозитории и заново импортируйте профиль на нужных устройствах.
